# 당하브릿지 2026

A3 신문 스타일의 4면 학교 소식지 웹앱입니다. 34개 동아리, 관리자 편집, 사진 업로드·크롭, 브라우저 저장과 JSON 백업을 지원합니다.

## 로컬 실행

Node.js 설치 후 프로젝트 폴더에서 `node preview.cjs`를 실행하고 http://127.0.0.1:4173/ 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 지면 구성 (4면)

| 면 | 내용 |
|---|---|
| 1면 | 당하의 발자취 · 배움의 새 공간 |
| 2면 | 스포츠클럽 특집 · 교실 밖 배움 |
| 3면 | 학생자치 이야기 · 꿈과 예술 |
| 4면 | 동아리 열전 (34개 동아리) |

기사 저장 키(`p0`~`p5`, `c0`~`c33`)는 그대로 유지되므로 기존에 저장한 편집 내용과 백업 파일도 그대로 불러올 수 있습니다.

## PC·모바일 화면

모든 기능(4면 열람, 관리자 편집, 사진 편집, 저장·백업, 인쇄)은 기기와 관계없이 동일합니다.

- **PC·태블릿 (768px 이상): A3 지면.** 한 면이 A3 용지 한 장(297×420mm) 크기로 보이며, `인쇄 / PDF`를 누르면 화면에 보이는 그대로 A3 한 장으로 출력됩니다. 본문 글자 크기는 내용이 한 장에 꼭 맞도록 자동으로 조절되고, 편집으로 글이 너무 길어져 한 장을 넘치면 지면 아래에 빨간 선과 안내가 표시됩니다. 창이 A3 폭보다 좁으면 화면에서만 비율을 줄여 보여 주며 인쇄는 항상 실제 크기입니다. 키보드 ← → 키로 면을 넘길 수 있습니다.
- **모바일 (767px 이하): 읽기 최적화.** 고정된 작은 헤더, 하단 지면 이동 바와 목차 창, 좌우로 밀어 면 넘기기, 1단 배치와 큰 본문 글자, 아래에서 올라오는 편집·사진 창을 제공합니다.

인쇄 시 프린터 설정에서 용지를 A3, 배율을 100%(실제 크기)로 지정하고 배경 그래픽을 켜 주세요.

화면 배치는 `dist/responsive.css`, 동작은 `dist/layout.js`에 있으며 `app.js`, `content.js`의 기능 로직을 그대로 사용합니다.

## 편집과 저장

관리자 접속 비밀번호는 `1234`입니다. 이 기능은 브라우저 편집 잠금이며 서버 인증이 아닙니다. 수정 내용과 사진은 저장 버튼을 누르면 해당 브라우저의 localStorage에 보관됩니다. 백업 내보내기로 별도 보관할 수 있습니다. 구글 시트 실시간 동기화는 연결되지 않았습니다.

## 콘텐츠

행사 기사에는 제공된 학교 행사 현황표의 내용을 반영했습니다. 미제공 정보는 자료 확인 중으로 표시하며, 2026년 10월 15일 이후 행사는 예정으로 안내합니다. 실제 발행 전에 내용을 검토하세요.

`dist/`가 정적 웹 배포 대상입니다. 인쇄/PDF 기능은 현재 선택된 면을 A3 한 장으로 인쇄합니다.
