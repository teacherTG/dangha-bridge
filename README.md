# 당하브릿지 2026

A3 신문 스타일의 8면 학교 소식지 웹앱입니다. 34개 동아리, 관리자 편집, 사진 업로드·크롭, 브라우저 저장과 JSON 백업을 지원합니다.

## 로컬 실행

Node.js 설치 후 프로젝트 폴더에서 `node preview.cjs`를 실행하고 http://127.0.0.1:4173/ 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 편집과 저장

관리자 접속 비밀번호는 `1234`입니다. 이 기능은 브라우저 편집 잠금이며 서버 인증이 아닙니다. 수정 내용과 사진은 저장 버튼을 누르면 해당 브라우저의 localStorage에 보관됩니다. 백업 내보내기로 별도 보관할 수 있습니다. 구글 시트 실시간 동기화는 연결되지 않았습니다.

## 콘텐츠

행사 기사에는 제공된 학교 행사 현황표의 내용을 반영했습니다. 미제공 정보는 자료 확인 중으로 표시하며, 2026년 10월 15일 이후 행사는 예정으로 안내합니다. 실제 발행 전에 내용을 검토하세요.

지면은 주제(담당 부서)별로 묶고, 같은 면 안에서는 시기순으로 배치합니다. 1면에는 교장선생님 인사말 자리가 있습니다. 기사별 사진 칸 수(0~3)는 `dist/content.js`의 `photoSlots`에서 정합니다.

`dist/`가 정적 웹 배포 대상입니다. 인쇄/PDF 기능은 현재 선택된 면을 A3 규격(297×420mm)으로 인쇄합니다.
