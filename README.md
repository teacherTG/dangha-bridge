# 당하브릿지 2026

B4 신문 스타일의 4면 학교 소식지 웹앱입니다. 34개 동아리, 관리자 편집, 사진 업로드·크롭, 브라우저 저장과 JSON 백업을 지원합니다.

## 로컬 실행

Node.js 설치 후 프로젝트 폴더에서 `node preview.cjs`를 실행하고 http://127.0.0.1:4173/ 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 지면 구성 (4면)

| 면 | 내용 |
|---|---|
| 1면 | 당하의 발자취 · 배움의 새 공간 |
| 2면 | 스포츠클럽 특집 · 교실 밖 배움 |
| 3면 | 학생자치 이야기 · 꿈과 예술 |
| 4면 | 동아리 열전 (34개 동아리) |

기사 저장 키(`p0`~`p5`, `c0`~`c33`)는 그대로 유지되므로 기존에 저장한 편집 내용과 백업 파일도 그대로 불러올 수 있습니다.

## PC·모바일 화면

모든 기능(4면 열람, 관리자 편집, 사진 편집, 저장·백업, 인쇄)은 기기와 관계없이 동일하게 제공되며, 화면 배치와 조작 방식만 기기에 맞게 달라집니다.

| | PC (1100px 이상) | 태블릿 (768~1099px) | 모바일 (767px 이하) |
|---|---|---|---|
| 지면 목차 | 왼쪽 고정 사이드바 | 상단 고정 가로 스크롤 칩 | 가로 스크롤 칩 + 하단 바의 목차 시트 |
| 면 이동 | 상단 ← → 버튼, 키보드 ← → 키 | 상단 ← → 버튼 | 하단 이동 바, 좌우 스와이프, 큰 "다음 면" 버튼 |
| 지면 | 신문형 넓은 지면, 메인 기사 2단 본문, 동아리 4열 | 2단 지면, 동아리 3열 | 1단 읽기, 큰 본문 글자, 동아리 1열 카드 |
| 편집 바 | 화면 하단 플로팅 바 | 하단 바 | 하단 2×2 버튼 (이동 바 위로 자동 배치) |
| 대화상자 | 가운데 모달 | 가운데 모달 | 바텀 시트 |

반응형 레이어는 `dist/responsive.css`와 `dist/layout.js`에 있으며 `app.js`, `content.js`의 기능 로직을 그대로 사용합니다.

## 편집과 저장

관리자 접속 비밀번호는 `1234`입니다. 이 기능은 브라우저 편집 잠금이며 서버 인증이 아닙니다. 수정 내용과 사진은 저장 버튼을 누르면 해당 브라우저의 localStorage에 보관됩니다. 백업 내보내기로 별도 보관할 수 있습니다. 구글 시트 실시간 동기화는 연결되지 않았습니다.

## 콘텐츠

행사 기사에는 제공된 학교 행사 현황표의 내용을 반영했습니다. 미제공 정보는 자료 확인 중으로 표시하며, 2026년 10월 15일 이후 행사는 예정으로 안내합니다. 실제 발행 전에 내용을 검토하세요.

`dist/`가 정적 웹 배포 대상입니다. 인쇄/PDF 기능은 현재 선택된 면을 B4 규격으로 인쇄합니다.
