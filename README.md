# 당하브릿지 2026

A3 신문 스타일의 4면 학교 소식지 웹앱입니다. 34개 동아리, 관리자 편집, 사진 업로드·크롭, 브라우저 저장과 JSON 백업을 지원합니다.

## 로컬 실행

Node.js 설치 후 프로젝트 폴더에서 `node preview.cjs`를 실행하고 http://127.0.0.1:4173/ 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 편집과 저장

관리자 접속 비밀번호는 `1234`입니다. 이 기능은 브라우저 편집 잠금이며 서버 인증이 아닙니다. 수정 내용과 사진은 저장 버튼을 누르면 해당 브라우저의 localStorage에 보관됩니다. 백업 내보내기로 별도 보관할 수 있습니다. 구글 시트 실시간 동기화는 연결되지 않았습니다.

## 콘텐츠

행사 기사에는 제공된 학교 행사 현황표의 내용을 반영했습니다. 미제공 정보는 자료 확인 중으로 표시하며, 2026년 10월 15일 이후 행사는 예정으로 안내합니다. 실제 발행 전에 내용을 검토하세요.

지면은 4면입니다. 1면(교장선생님 인사말·학교 상징·교과/국제교류), 2면(스포츠·학생자치), 3면(교실 밖 배움·진로), 4면(동아리 34). 면은 주제(담당 부서)별로 묶고, 같은 면 안에서는 시기순으로 배치합니다. 기사·사진 칸 수는 `dist/content.js`의 `pages`에서 정하고, 본문이 빈 기사는 '내용 필요'로 표시됩니다. 각 면은 A3 한 장에 들어가도록 넘칠 때만 자동으로 축소됩니다.

기사 사진은 `dist/photos/`에 있고 `dist/content.js`의 `seeds`에서 기사와 연결합니다. 같은 줄의 사진은 높이를 맞추고 원본 비율대로 폭을 나눕니다. 편집 모드에서 등록한 사진은 해당 브라우저에서 이 기본 사진보다 우선합니다.

`dist/`가 정적 웹 배포 대상입니다. 인쇄/PDF 기능은 현재 선택된 면을 A3 규격(297×420mm)으로 인쇄합니다.
